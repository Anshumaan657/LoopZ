# Contract feature

Phase 5.4 compiles the saved intake and interview through the provider-neutral Phase 5.1–5.3
pipeline, then presents goal, deliverables, scope, assumptions, acceptance criteria, evidence, commands,
findings, and restrictions for review. Users may edit content and priority while stable IDs and list
shape remain locked. Every save reruns safety generation and deterministic validation. Browser-local
progress is saved in the existing project record; confirmation and immutable versions belong to
Phase 5.5.
