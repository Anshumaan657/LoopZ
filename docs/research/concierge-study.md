# Concierge validation protocol

## Objective

Determine whether the LoopZ workflow improves real coding-agent outcomes before automating the full product.

## Participants

- 5–10 freelancers or technical indie builders.
- 10–20 genuine small web tasks.
- At least five complete agent runs with returned evidence.

## Procedure

1. Preserve the participant's rough request.
2. Ask no more than five high-impact questions.
3. Confirm scope and non-goals.
4. Create LoopSpec Lite manually.
5. Generate a Codex-ready task.
6. Collect the final report, tests, corrections, and time spent.
7. Assess completion by criterion.
8. Generate a repair task if necessary.
9. Ask whether the participant would reuse or pay for the workflow.

## Capture

- Clarification turns.
- Criteria passed.
- Evidence coverage.
- Human corrections.
- Repair attempts.
- Agent-side and total tokens when available.
- Time to acceptable completion.
- Return and reuse intent.

## Decision

Continue only if users value the contract plus evidence/repair cycle—not merely the appearance of a detailed prompt.
