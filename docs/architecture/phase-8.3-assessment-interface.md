# Phase 8.3 — Assessment results interface

`/runs/[runId]/assessment` is now a real run-linked screen rather than a placeholder.

The screen presents:

- Overall submitted-evidence outcome and recommended next action.
- Supported and attention-required counts.
- Criterion requirement, agent claim, evidence status, confidence, and strongest evidence type.
- Missing evidence and contradictions.
- Expandable original evidence content for criterion-to-evidence traceability.
- A clear notice that LoopZ did not access the repository or rerun commands.

Failed or incomplete runs are prepared for the Phase 9 focused repair flow. Completed runs are prepared for the Phase 9 terminal-state action.
