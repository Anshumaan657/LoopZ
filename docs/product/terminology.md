# Product terminology

| Internal term | User-facing wording |
|---|---|
| LoopSpec | Project contract |
| Loop compiler | AI build-instruction generator |
| Acceptance criteria | How we will know it works |
| Evidence submission | Return your results |
| Criterion assessment | Completion check |
| Repair loop | Focused fix instructions |
| Unsupported claim | No supporting result provided |
| Terminal state | Current outcome |

Avoid promises such as “exact output,” “guaranteed verification,” or “works with every agent.”
