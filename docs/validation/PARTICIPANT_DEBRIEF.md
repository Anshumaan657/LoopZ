# Participant Debrief

Conduct this after assessment and any bounded repair. Prefer a 10–15 minute call; do not sell the product during the interview.

## Questions

1. Before today, how would you normally give this task to a coding agent?
2. Which part of the LoopZ process was most useful, if any?
3. Which part felt slow, repetitive, confusing, or unnecessary?
4. Did the confirmed scope match what you meant? What was missing or over-specified?
5. Did the generated task change the agent's behavior in a way you noticed?
6. Was the independent evidence assessment useful beyond the agent's final report? Why?
7. Would you use this process for another real task? Ask for a specific next task rather than accepting a polite yes.
8. What would stop you from using it again?
9. Would you pay for this outcome? If yes, what pricing unit feels natural: per task, monthly, or team plan?
10. What would need to be true before you would recommend it to another builder?

## Behavioral Signals

Record these separately from opinions:

- Returned with evidence without repeated chasing
- Supplied a second real task
- Introduced another potential participant
- Asked when an automated version would be available
- Volunteered a price or accepted a concrete price test
- Abandoned after receiving the generated task
