# Participant Recruitment

## Target profile

Recruit people who satisfy all required criteria:

- Builds small web applications or features.
- Has used a coding agent at least twice.
- Has a real task intended for execution within the next two weeks.
- Can provide the agent's final report and test/build output.
- Can share the request and results without violating client or employer obligations.

Useful but not required:

- Freelancer or technical indie builder.
- Familiar with Git and test commands.
- Has previously experienced agent misunderstanding or rework.

## Exclude

- People with only hypothetical project ideas.
- People unable to share any execution outcome.
- Tasks containing credentials or confidential data that cannot be anonymized.
- High-risk medical, financial, legal, security-sensitive, or critical-infrastructure work.
- Tasks requiring unauthorized access or destructive actions.
- People expecting LoopZ to execute or deploy the project for them.

## Screening questions

1. Which coding agent do you currently use?
2. How many real tasks have you completed with it?
3. What small web-development task do you intend to run?
4. Is it a new project or an existing repository?
5. Can you share the final report and test/build output?
6. Do you have permission to share the task details used in this study?
7. Can you complete the run and return within seven days?

## Short recruitment message

> I am testing LoopZ, a workflow that turns a rough development request into a confirmed, evidence-based task for a coding agent. I am looking for developers, freelancers, and indie builders with one real small web task. The session takes about 20–30 minutes, followed by running the task in your usual coding agent and returning its final report or test output. This is product research, not a sales call. Interested?

## Detailed recruitment message

> I am validating an early product called LoopZ. It is designed for people who use Codex, Claude Code, Cursor, or similar coding agents and lose time because requirements are incomplete or the agent claims completion without enough evidence.
>
> You bring one real, bounded web-development task. I preserve your original request, ask up to five focused questions, and manually create a project contract, acceptance criteria, and a copy-ready agent task. You run it in your existing coding agent and return the final report and test/build evidence. I then assess the result and, if necessary, create a focused repair task.
>
> Participation includes a 20–30 minute setup session plus a short follow-up after execution. Please do not share secrets or information you are not authorized to disclose. If you are interested, reply with the coding agent you use and a one-sentence description of the task.

## Follow-up message

> Thanks for your interest in the LoopZ validation study. Before scheduling, please send: (1) the coding agent you use, (2) whether the project is new or existing, (3) the rough task exactly as you would normally give it to the agent, and (4) confirmation that you can share the final report and test/build output. Do not include credentials or private client information.
