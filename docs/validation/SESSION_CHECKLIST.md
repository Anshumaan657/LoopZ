# Concierge Session Checklist

## Before Intake

- [ ] Assign participant and experiment IDs.
- [ ] Confirm the participant has a real, permitted task.
- [ ] Read the consent script and record permissions.
- [ ] Create the ignored private experiment directory.
- [ ] Ask the participant not to share secrets or private customer data.

## Intake and Clarification

- [ ] Preserve the original request unchanged.
- [ ] Apply the rejection rules.
- [ ] Ask no more than five risk-based questions.
- [ ] Record category codes for every question.
- [ ] Separate user facts, repository facts, and facilitator assumptions.

## Contract Generation

- [ ] Create the plain-language project specification.
- [ ] Define stable, testable acceptance criteria.
- [ ] Define required evidence for every criterion.
- [ ] Create LoopSpec Lite.
- [ ] Generate the agent-ready task.
- [ ] Obtain explicit scope confirmation before execution.

## Execution and Return

- [ ] Record coding agent and model.
- [ ] Preserve the original-prompt baseline when the comparison design calls for it.
- [ ] Collect the complete final report and raw evidence.
- [ ] Record corrections and repair attempts.
- [ ] Do not silently fix the participant's output before assessment.

## Assessment and Debrief

- [ ] Independently assess every criterion.
- [ ] Mark unsupported claims as unverified.
- [ ] Generate a bounded repair only when justified.
- [ ] Conduct the participant debrief.
- [ ] Update the workbook and failure-pattern log.
- [ ] Sanitize aggregate insights before adding them to tracked files.
